# Inverse Kinematics Simulation

A small interactive inverse-kinematics simulation built with Python and Pygame. An articulated arm follows a target position, demonstrating how inverse kinematics can be used to calculate movement toward a goal.

## Controls

- Press **M** to change the target position.

## Tech stack

- Python
- Pygame
- Inverse kinematics / interactive simulation

## Run locally

1. Clone the repository:

   ```bash
   git clone https://github.com/TobiasAboh/Inverse-Kinematics-simulation.git
   cd Inverse-Kinematics-simulation
   ```
2. Install Pygame if it is not already installed:

   ```bash
   python -m pip install pygame
   ```
3. Run the project's Python entry point. Check the source files for the script name.

## Purpose

This project explores interactive graphics, target tracking, and the use of inverse-kinematics concepts to control an articulated arm.
